## 问题清单

### 必须修复（已完成）

1. NexusPHP 正则被站点嵌套表格提前截断，导致 `&nbsp;` 标题、0 B 体积和重复候选；0.57 改为标准库结构化解析并按下载链接去重。
2. MoviePilot 当前模型要求 `MediaInfo.year` 为字符串，下载因子使用 `downloadvolumefactor`；0.57 已在客户端边界完成契约转换。

### 建议优化

- 站点G在本轮实际搜索与选择性重试中均于约 15 秒后 `ReadTimeout`，现已能被结构化记录且不阻塞其他站点；建议在 Web 中单独提高超时或暂时取消参与搜索。
